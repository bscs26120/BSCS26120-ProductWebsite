# AR Store Website

This website is an **AR Store** created to display different products such as watches, shoes, purses, mobile phones, and sunglasses. The purpose of the website is to provide a simple and attractive online store where users can view product names, prices, availability, images, and short descriptions. It also includes a Home page, Products page, and Contact page so users can easily navigate the website.

The website was built using **HTML and CSS**. HTML was used to create the structure of the pages, including headings, images, product information, buttons, and links. CSS was used to design the website, including colors, spacing, boxes, fonts, and the overall layout. The same navigation style is used across the pages to make the website simple and easy to use.
